# assets

The terrain is emitted as shaded geometry rather than assembled from a tile
atlas — four corner heights per tile means arbitrary elevation joins, and no
hand-authored tile set stitches those cleanly. So there is nothing to load yet,
and `src/platform/gs_paths.c` probes for this directory rather than needing it.

What lands here, and when:

- ~~**Vehicle sprites**~~ — **done, and not sprites.** The cars are meshes,
  generated by `tools/make_meshes.py` from a parameter table and committed as
  `src/gfx/gs_meshes.c`. Sprites would have had to quantise heading, pitch and
  roll; geometry under a fixed camera quantises none of them, and a boxy 1985
  silhouette at low poly needs no textures at all. `ATTRIBUTION.md` here is
  written by that same script in the same run.
- **Surface textures** over the shaded triangles, if they turn out to be needed.
- **Sounds**, generated rather than sampled.
- **The stock tracks**, once there is an editor to author them with. They will
  be ours: the original's fifty are EA's, and are for calibrating against, not
  for shipping.

Whatever arrives here is generated by something in `tools/`, and its attribution
is generated in the same run — a licence condition is not documentation.
